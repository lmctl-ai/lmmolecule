# CI

Same shape as lmnum and lmspace: five jobs (`linux-x64`, `linux-arm64`, `macos-arm64`, `macos-x64`,
`windows-x64`), each syncing pinned dependencies (`scripts/sync-deps.sh`), verifying `sdk.lock`,
installing `@lmctl-ai/lmctl@0.2.420` for `lmscript`, running `./test.sh` with
`LMMOLECULE_TEST_NETWORK=1` (so the `lmplot` combo pipeline downloads `lmplot`'s release), then
uploading `lmmolecule-<platform>[.exe]` plus `LICENSE` and `THIRD_PARTY_NOTICES`. A `v*` tag adds
the `release` job, which checks `--version` against the tag and attaches the five platform binaries
with `gh release`.
